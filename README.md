# Basbousa Bliss - Static Store

## Description
Basbousa Place is a static e-commerce storefront landing page built during the initial phase of my frontend development studies. The primary objective of this project was to master core semantic HTML5 structures, execute baseline CSS3 styling, manage local image assets, and implement fundamental typography configuration before moving into complex layout frameworks.

## Live Demo
Explore the live store here: (https://nadaalafify.github.io/Basbousa-Bliss-Store/)

## Tech Stack
- **HTML5:** Defining foundational document structures, list architectures for product categorization, and anchor elements for site navigation.
- **CSS3 (Pure CSS):** Handling basic box models (margins, borders, padding), native typography sizing, and elementary color theory coordination.

## Key Features and Technical Execution
- **Foundational E-Commerce Layout:** Constructed a traditional web presentation showcasing varied product tiers and descriptions using static document flows.
- **Core Semantic Elements:** Practiced the implementation of structural containers and divider blocks to separate menu options cleanly.
- **Custom Color Management:** Applied a specific, thematic color palette aligned with the brand identity using raw CSS property declarations.
- **Structural Code Base:** Developed entirely by hand without automation tools to ensure a strict understanding of native browser interpretation and raw element behavior.
